## Rules

1. **Use first.** Attach an existing file if it fits. Logo for identity; mascot for a lab beat.
2. **Make second.** New stills only via `image_edit` with one or more paths from this folder as `image`. Never `image_gen` the G wordmark or CRT mascot from text alone.
3. **No fake glass.** Do not generate STATUS / `v0.1.N` / Dual DoD text. Operator glass photos are evidence attachments, separate from brand art.
4. **Write new files** to `media/pr/<slug>.jpg` (or `.png`). Do not overwrite the table above.
5. **Aspect:** X 1:1 or 16:9 from the logo; Patreon banner 16:9 from logo + mascot.
